Setuper — Documentation

Everything you need to bulk-manage channels and roles, snapshot a server, and apply layout templates.

Setup

Install Setuper, choose a log channel, and confirm the required permissions before running your first bulk action.

Status

Channels & roles

Bulk-create or delete channels and roles, move categories, and apply permission overwrites in a single pass.

Snapshots

Capture a full JSON record of a guild's channels and roles, then review it before restoring anything from it.

Layout exports

Export the current layout of a guild as a JSON file, for archiving or for applying to another server.

Permission templates

Save custom permission templates with /template and reuse them across categories, channels, and roles.

Delete by ID

Clean up a batch of channels or roles created in a single action, using the record Setuper kept when they were created.

Reference

Every command Setuper exposes.

Group Commands
Configuration /setlog, /clearlog
Channels Bulk create, bulk delete, move category
Roles Bulk create, bulk delete, apply permissions
Snapshots /snapshot, review, restore
Layout /export, /template
