## About

CoreLine Productions builds and maintains Discord bots that solve specific problems for server operators. This repository is the public face of every bot we run — its documentation, its live status, its privacy policy, and the terms that govern its use.

Everything here is deployed straight from `main` via GitHub Pages. No build step. No backend. No third-party hosting.

## Bots

### <img src="https://coreline-productions.github.io/coreline/assets/tixal.svg" alt="" width="22" height="22" /> Tixal

Ticket management, built for teams that take support seriously. Panels, private ticket channels, claim workflows, staff stats, ratings, blacklists, notes, transcripts, and reminders — everything a support desk needs, in one bot.

**[Documentation](https://coreline-productions.github.io/coreline/docs/tixal/)** · **[Status](https://coreline-productions.github.io/coreline/bots/tixal/)** · **[Privacy](https://coreline-productions.github.io/coreline/privacy/tixal/)**

## Live status

Every bot publishes a signed heartbeat to this repository on a fixed interval. The status pages read that data client-side, so what you see is the state of the bot one heartbeat ago — not a cached guess.

| | |
|---|---|
| **[Global status](https://coreline-productions.github.io/coreline/status/)** | All services at once |
